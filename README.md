# Программчлалын шалгалт

4, 6–12-р ангийн Программчлалын хичээлийн 1-р улирлын хөндлөнгийн шалгалтыг онлайнаар авах вэб.
Асуулт, хариултын түлхүүр, рубрикийг `../materials/` доторх PDF-үүдээс `src/content/`-д хөрвүүлсэн.

## Юу хийдэг вэ

**Сурагч** шалгалтын код, нэр, сурагчийн кодоо оруулж эхэлнэ.

- **А хэсэг (онол, 20 мин):** олон сонголттой асуулт, нүд бөглөх, код бичих, блок схем зурах даалгавар.
- **Б хэсэг (практик, 40 мин):** браузер дээр Python ажиллуулах (`input()` ажиллана), HTML/CSS-ийн шууд харагдац, олон файлтай React, блок схем зурагч.
- Хариулт автоматаар хадгалагдана. Цаг дуусахад автоматаар илгээгдэнэ.
- **Focus mode:** сурагч өөр таб руу шилжих, цонхоо жижигрүүлэх (хуудас 1.5 секундээс удаан харагдахгүй болох) бүрт анхааруулга гарч, тоологдоно. Хязгаарт хүрвэл (анхдагч 3) шалгалт автоматаар дуусна. Хаягийн мөр, хөтчийн popup, өөр програм руу 2 секундээс удаан шилжихийг тоолохгүй, зөвхөн багшид хугацаатай нь харуулна (ийм зүйл шалгалтаас үл хамааран тохиолддог тул). Тоолуур сервер дээр хадгалагддаг тул хуудсыг refresh хийж тэглэх боломжгүй. Багш шалгалт бүрийн тохиргооноос хязгаарыг өөрчилж (0 = зөвхөн бүртгэнэ), санамсаргүй тохиолдолд сурагчийн тоолуурыг тэглэж болно.
- 4-р ангийн практик нь вэб дээрх 2 шивэх дасгал (П1 3 мин, П2 5 мин). Хурд (үг/мин), нарийвчлалыг (%) систем бодож оноо өгнө. Хурдыг бүтэн хугацаагаар тооцох тул эрт зогсоовол хурд өсөхгүй. Зөв арга барилыг багш ажиглаж оноо өгнө. Шивэх текст, хугацааг асуулт засварлагчаас өөрчилж болно.
- Б хэсгийг өгөлгүй дууссан сурагчид байвал (жишээ нь Б хэсэг офлайн байх үед өгсөн) шалгалтын «Сурагчид» хэсэгт «Б хэсгийг нээх» товч гарна. Сурагч кодоороо дахин орж Б хэсгийг гүйцэтгэнэ, цаг нь орж ирэхэд эхэлнэ.

**Багш** (`/admin`):

- Шалгалтыг нээж хаана, код үүсгэнэ, сурагчдын явцыг шууд харна.
- Хугацаа сунгах, өөр компьютерээс үргэлжлүүлэхийг зөвшөөрөх, шалгалтыг дуусгах боломжтой.
- Олон сонголттой асуулт болон нүдтэй даалгаврыг систем автоматаар шалгана.
- Задгай, практик даалгаврыг багшийн хөтчийн рубрикээр (0.5-ын нарийвчлалтай) үнэлнэ. Сурагчийн кодыг тэнд нь ажиллуулж үзэх боломжтой.
- Нэгж бүрийн дундаж гүйцэтгэлийг харна (60%-иас доош бол улаанаар тэмдэглэнэ). Дүнг Excel (CSV) хэлбэрээр татна.
- Асуулт засах, нэмэх, устгах, багш нэмэх боломжтой.

## Supabase + Vercel-д байршуулах

1. **Supabase** дээр шинэ төсөл үүсгэнэ. Project Settings → Database → Connection string → **Transaction pooler** холбоосыг хуулна.
2. Энэ хавтсанд `.env.local` файл үүсгээд `.env.example`-ийн дагуу `DATABASE_URL`, `SESSION_SECRET` утгуудыг бичнэ.
3. Хүснэгтүүдийг үүсгэж, шалгалтуудыг болон өөрийн багшийн бүртгэлийг оруулна:
   ```bash
   npm install
   npm run db:migrate
   npm run db:seed -- --teacher таны@имэйл.mn "Таны нэр" нууцүг123
   ```
   Seed нь 16 шалгалт (8 анги × 2 хувилбар) оруулж, кодыг нь хэвлэнэ. Бүх шалгалт хаалттай байдлаар орно.
   Дахин ажиллуулахад байгаа шалгалтыг дарж бичихгүй. Агуулга өөрчлөгдсөн бол нэг ангийн асуултуудыг
   `npm run db:seed -- --replace 4 B` (зөвхөн Б хэсэг) эсвэл `--replace 4` (бүхэлд нь) гэж шинэчилнэ. Код,
   нээлттэй эсэх хэвээр үлдэнэ. Ижил дугаартай асуултыг байранд нь шинэчлэх тул сурагчийн хариулт холбоотой
   үлдэнэ. Хариулттай асуултыг устгах эсвэл шалгуурын тоог өөрчлөх бол тухайн шалгалтыг юу ч өөрчлөхгүйгээр алгасна.
   Даалгаврын зургийг `public/tasks/`-д хадгалж, prompt-д `![тайлбар](/tasks/файл.png)` гэж оруулна.
4. **Vercel** дээр энэ хавтсыг (`web/`) төсөл болгон оруулна. Environment Variables хэсэгт `DATABASE_URL`, `DB_POOL_MAX=5`, `SESSION_SECRET`, `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` хувьсагчдыг нэмнэ. Function Region-ийг Supabase-тай ижил бүсэд тохируулна.
5. Байршсан хаягийн `/admin` хуудсаар нэвтэрнэ.
6. Supabase-ийн Free (0.5 GB RAM) дээр санах ойг хэмнэхийн тулд Database → Settings → Connection pooling хэсэгт **Pool size**-ийг 8 болгоно. Апп-ын query бүр 1 ms хүрэхгүй тул энэ хангалттай. Мөн апп ашигладаггүй **Data API**-г Project Settings → Data API хэсгээс унтраана. Сервер Postgres-тэй шууд холбогддог.

## Supabase Realtime

`npm run db:migrate` нь Supabase дээр `db/realtime.sql`-ийн trigger-үүдийг суулгана. Сурагч орох, хэсэг илгээх, оноо өөрчлөгдөх бүрд `exam:<id>` болон `exams` сувгаар дохио илгээгддэг. Дохионд өгөгдөл байхгүй. Багшийн самбар дохио хүлээн аваад өгөгдлөө серверээс шинээр уншина. Ингэснээр сурагчдын мэдээлэл нийтийн түлхүүрээр ил гарахгүй. `NEXT_PUBLIC_SUPABASE_*` хувьсагч тохируулаагүй үед самбар 15 секунд тутам шинэчлэгдэнэ.

## Локалд ажиллуулах

Docker шаардлагагүй. PGlite нь локал Postgres болж ажиллана.

```bash
npm install
npm run db:local          # нэг терминалд: 5433 порт дээр Postgres
cp .env.example .env.local
# .env.local: DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5433/postgres
#             DB_POOL_MAX=5, SESSION_SECRET=<openssl rand -hex 32>
npm run db:migrate
npm run db:seed -- --teacher teacher@test.mn "Туршилтын багш" testpass123
npm run dev               # http://localhost:3000, багш: /admin
```

## Аюулгүй байдал

- Хариултын түлхүүр, рубрик зөвхөн сервер дээр байдаг тул сурагчийн хөтөч рүү илгээгддэггүй.
- Хугацааг сервер шалгадаг. Хугацаа дууссаны дараа ирсэн хариултыг хүлээж авахгүй.
- Нэг сурагчийн кодоор нэг л төхөөрөмж ашиглана. Өөр компьютерээс үргэлжлүүлэхийн тулд багш зөвшөөрөл өгнө.
- Сурагчийн HTML/React код тусгаарлагдсан (`sandbox`) iframe-д ажилладаг тул багшийн хуудсанд нөлөөлөхгүй.
- DB хүснэгтүүд дээр RLS асаалттай тул Supabase-ийн нийтийн API-аар уншиж болохгүй.
